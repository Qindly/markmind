# 27. 编辑页左上角状态区收口

## 本次任务做了什么
本次继续收紧编辑页左侧辅助区域的视觉层级，重点做了两件事：
- 将原本居中展示的文档状态区改成左上角的紧凑概览卡片
- 让左侧固定栏变成“顶部概览卡片 + 下方 TOC 导航”的单列结构

## 涉及的文件清单
- 编辑页布局：web/src/features/editor/components/EditorWorkspace.tsx
- 左上角概览卡片：web/src/features/editor/components/EditorInfoPanel.tsx

## 核心设计决策和原因
- 状态区改为一张紧凑卡片后，视觉权重明显低于 TOC，更符合“辅助信息”而不是“主内容”的定位。
- 桌面端左侧固定栏保持同宽单列，顶部状态卡片与 TOC 卡片在宽度上完全统一，页面结构更稳定。
- TOC 保持占据左侧剩余高度并继续独立滚动，避免状态信息挤压导航的主要可视空间。
- 小屏端仍然使用流式布局，让状态区和 TOC 顺序堆叠，避免 fixed 结构遮挡正文。
