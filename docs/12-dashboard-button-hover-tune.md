# 12-dashboard-button-hover-tune

## 本次任务做了什么

针对首页 Dashboard 的视觉细节继续做了一轮小幅微调：降低右侧“新建空文档”按钮的视觉权重，并统一左侧目录项和右侧文档项的悬浮反馈颜色，让这类小型选项式组件与浅色按钮使用同一套 hover 语义。

## 涉及文件清单

- `web/src/features/dashboard/components/DocumentListPanel.tsx`
- `web/src/features/dashboard/components/FolderSidebar.tsx`

## 核心设计决策和原因

1. 新建空文档按钮降级为次要操作
   - 将右侧“新建空文档”按钮改为浅色按钮，并把尺寸缩小到接近左侧“新建文件夹”按钮。
   - 这样首页主视觉会回到列表内容本身，而不是被黑色操作按钮抢走注意力。

2. 选项式组件统一 hover 语义
   - 左侧目录项与右侧文档项都改为使用浅色按钮同款 hover 背景色。
   - 后续这类“小型选择项”都可以沿用同一套悬浮反馈规则，避免页面内部交互反馈不统一。

## 前端结构与数据流

- 本次只调整 Dashboard 样式，不改任何数据流、状态逻辑和接口调用。
- 文档创建、目录选择、文档选择的交互逻辑完全保持不变。

## 已知 TODO / 待改进项

- 如果后续首页继续增加批量操作、排序、筛选等轻量操作按钮，也可以统一沿用这套次要按钮尺寸与 hover 语义。
