# 13-dashboard-selected-state-color

## 本次任务做了什么

为首页 Dashboard 左侧目录项和右侧文档项补上了更明显的选中态颜色。新的选中色采用比 `#3C3C3B` 稍深一点的深灰色，让当前选中的文件夹或文档在列表里能够被更直观地识别出来。

## 涉及文件清单

- `web/src/styles/globals.css`
- `web/src/features/dashboard/components/FolderSidebar.tsx`
- `web/src/features/dashboard/components/DocumentListPanel.tsx`

## 核心设计决策和原因

1. 选中态需要有明确的色块区分
   - 之前首页的选中态只有边框变化，视觉上不够明确。
   - 这次改为深灰色选中背景，让当前上下文一眼可见。

2. 选中色保持克制，不回到纯黑按钮感
   - 新的选中色比 `#3C3C3B` 再深一点，但仍然控制在柔和深灰范围内。
   - 这样既能突出选中态，又不会像大面积纯黑块那样抢走页面重心。

3. 选中态的辅助文字同步提亮
   - 文件夹标签、ROOT 标识、文档更新时间等次级信息，会在选中时统一切到更浅的辅助字色。
   - 保证深色底上的信息层级仍然清晰可读。

## 前端结构与数据流

- 本次只修改列表项的选中视觉，不改任何业务逻辑和交互行为。
- 目录选择与文档选择的状态流维持现有实现。
